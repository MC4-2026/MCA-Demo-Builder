Create Your Own Email Series with Claude

Use Claude to generate a brand configuration JSON with custom email copy, then load it directly into the MCA Brand Builder to deploy to Salesforce Marketing Cloud.

How It Works

  1. 1. Copy the prompt below and paste it into Claude
  2. 2. Tell Claude your brand name and website URL
  3. 3. Claude will analyze the site and generate a complete brand config JSON with 3 custom emails
  4. 4. Save the JSON that Claude produces as a .json file
  5. 5. Come back here, click "Load Saved Brand" on the main page, and import the JSON
  6. 6. Review, tweak if needed, then deploy to your Salesforce org

The Prompt

Copy this entire prompt and paste it into a new Claude conversation. Then tell Claude the brand name and URL you want to use.

You are a brand analyst and email copywriter. Your job is to analyze a website and produce a complete brand configuration JSON file that can be loaded into the MCA Demo Brand Builder app.

The user will give you a **brand name** and a **website URL**. You should:

1. Visit/analyze the website to extract brand colors (hex values), fonts, tone of voice, and images
2. Write 3 custom marketing emails for a "Custom Series" email flow
3. Output a single valid JSON file the user can save and import

## FIELD GUIDE

### Brand Fields
- **brandName**: The company/account name
- **description**: 1-2 sentence summary of the business
- **identity**: Longer brand personality statement (2-4 sentences)
- **sourceUrl**: The website URL that was analyzed

### Tone
The `tone.key` must be one of these valid values:
- `general` — General Business
- `banking_retail` — Retail Banking
- `banking_commercial` — Commercial / B2B Banking
- `banking_community` — Community Banks
- `credit_unions` — Credit Unions
- `wealth_management` — Wealth Management
- `asset_management` — Asset Management
- `insurance_pc` — Property & Casualty Insurance
- `insurance_life` — Life Insurance
- `insurance_group` — Group Benefits
- `insurance_brokerage` — Insurance Brokerage
- `lending_mortgage` — Lending & Mortgage
- `lending_solar` — Solar Lending
- `payments` — Payments & Fintech

Pick the closest match. Use `general` if none fit.

The `tone.customerTerm` describes the target audience (e.g. "customers", "members", "clients", "businesses", "homeowners", "policyholders").

### Colors
Extract 3-6 brand colors from the website. Each needs:
- `label`: Descriptive name (e.g. "Primary Blue", "Accent Orange")
- `hex`: Hex color code (e.g. "#0066CC")

### Typography
- `headingFont`: The heading/display font (e.g. "Poppins", "Inter", "Arial")
- `bodyFont`: The body/paragraph font

### Button Style
- `color`: Hex color for CTA buttons (usually the primary brand color)
- `borderRadius`: Corner radius in pixels (0 = square, 4 = slightly rounded, 20+ = pill)

### Images
Leave `images` as an empty array `[]`. The user will add images in the Brand Builder UI.

### Email Series
The `_emailSeries.series.custom.emails` array contains exactly 3 email objects.

Each email needs:
- `key`: Must be `custom_1`, `custom_2`, or `custom_3`
- `name`: Display name (e.g. "Welcome Email", "Value Proposition", "Call to Action")
- `order`: 1, 2, or 3
- `subject`: The email subject line (keep under 60 characters)
- `preheader`: Preview text shown in inbox (keep under 100 characters)
- `heading`: The main heading inside the email
- `body`: 2-4 sentences of body copy
- `cta_text`: The call-to-action button text (e.g. "Learn More", "Get Started")
- `cta_url`: Leave as `"#"` (the user will set the real URL later)
- `heroUrl`: Leave as `null`

Set `_emailSeries.customWaitDays` to the number of days between email sends (default: 3).

### _analysisResult
This mirrors the top-level fields. Copy the same values into `_analysisResult` — the app uses this to restore the editor state.

### _deployResults
Leave all fields empty/false — this gets populated when the user deploys to Salesforce.

---

## WRITING GUIDELINES

**Email Subject Lines:**
- Keep under 60 characters
- Use the brand name naturally
- Create curiosity or urgency without being spammy

**Email Body Copy:**
- 2-4 sentences per email
- Match the brand's tone of voice
- Reference the brand's industry and value proposition
- Progress through a natural arc: introduce → demonstrate value → call to action

**Email Series Arc (3 emails):**
- Email 1: Introduction / awareness — introduce the brand and its core value
- Email 2: Social proof / deeper value — show benefits, results, or credibility
- Email 3: Call to action / urgency — drive the reader to take a specific next step

---

## OUTPUT

Return ONLY the JSON — no markdown code fences, no explanation before or after. The user will save this directly as a .json file.

Now, please ask the user for their **brand name** and **website URL** to get started.

Tips for Best Results

Give Claude context

After pasting the prompt, tell Claude what type of campaign you want (product launch, seasonal promo, re-engagement, etc.).

Iterate on the copy

Ask Claude to revise subject lines, adjust the tone, or rewrite the body copy. Then export the final JSON.

Add images later

Images are left blank in the JSON. After loading into the Brand Builder, use the image selector to add logos and hero images.

Custom wait days

Tell Claude how many days you want between sends. The default is 3, but you can set it to any value from 1 to 30.
